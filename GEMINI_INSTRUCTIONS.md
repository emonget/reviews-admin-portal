# Project guidelines
## Coding
### Style
- prefer simple, brief errors checking to limit code verbosity
- prefer ternary operator over if blocks
- limit boilerplate code at max
### Checklist
- build check: npm run build
- lint check: npm run lint

## Development
### Prompts
- when in doubt ask user to provide more details 
- before implementing things that weren't specifically requested by user, ask his approval before doing it
